# Organiza e reúne informações essenciais para auxiliar na preparação da declaração.
Criar uma ferramenta no Excel que ajude a organizar e reunir informações essenciais para a declaração de imposto de renda

Ferramenta de Organização para Declaração de Imposto de Renda

📌 Sobre o projeto

Este projeto consiste na criação de uma ferramenta em planilha eletrônica desenvolvida para organizar e reunir informações importantes que podem ser utilizadas como apoio na preparação da declaração de Imposto de Renda.

A proposta é centralizar, em um único arquivo, informações pessoais do titular, dados de rendimentos bancários e observações/documentos relacionados, facilitando a consulta e a organização das informações durante o período de declaração.

Importante: esta ferramenta tem finalidade de organização e controle de informações. Ela não substitui o programa oficial da Receita Federal, uma análise tributária profissional ou a orientação de um contador.

🎯 Objetivo

O objetivo do projeto é criar uma ferramenta simples e visual que ajude o usuário a:

organizar seus dados pessoais;

reunir informações necessárias para consulta durante a declaração;

registrar rendimentos e valores informados por instituições bancárias;

manter referências a documentos e anexos;

reduzir a dispersão das informações em diferentes arquivos;

facilitar a conferência dos dados antes do preenchimento da declaração.

🧩 Estrutura da ferramenta

1. Dados do Titular

Área destinada ao cadastro das informações básicas do titular, incluindo:

Nome;

CPF;

Data de nascimento;

Título de eleitor;

Cônjuge;

Endereço;

CEP;

Telefone;

Celular;

E-mail;

Informações complementares.

2. Informes de Rendimentos Bancários

Área destinada à organização dos informes de rendimentos fornecidos pelas instituições bancárias.

Para cada banco podem ser registrados:

Instituição financeira;

Valor atual;

Referência do informe/documento;

Anexo ou nome do arquivo correspondente.

A seção também possui um campo de TOTAL para reunir os valores registrados.

3. Notas

Área destinada a observações e pendências, podendo ser utilizada para:

lembrar documentos que ainda precisam ser obtidos;

registrar informações que precisam ser conferidas;

fazer observações sobre bancos ou rendimentos;

controlar pendências antes do preenchimento da declaração.

🧭 Navegação

A planilha possui uma interface lateral para facilitar o acesso às áreas:

TITULAR — dados cadastrais;

INFORMES — rendimentos e informações bancárias;

NOTAS — observações e pendências.

Também foram utilizados botões de PRÓXIMO e ANTERIOR para facilitar a navegação entre as etapas.

📎 Organização de documentos

A ferramenta permite relacionar as informações registradas aos respectivos documentos ou informes.

A ideia é manter uma relação organizada entre:

Instituição → Informação registrada → Documento de origem

Isso facilita a localização e a conferência dos documentos utilizados como fonte das informações.

🔄 Fluxo de utilização

Uma forma recomendada de utilizar a ferramenta é:

Preencher os dados do titular;

Inserir os informes e valores das instituições bancárias;

Identificar os documentos correspondentes;

Conferir os valores registrados;

Utilizar a área de Notas para pendências e observações;

Revisar as informações antes de utilizá-las no preenchimento da declaração.

💡 Problema que o projeto busca resolver

Durante a preparação da declaração de Imposto de Renda, informações importantes podem estar espalhadas em diferentes documentos, e-mails, arquivos PDF e planilhas.

A ferramenta busca solucionar esse problema por meio da centralização e organização das informações, permitindo que o usuário tenha uma visão mais clara dos dados que precisa consultar.

Dessa forma, a planilha funciona como um painel de organização para as informações relacionadas à declaração.

⚠️ Observações importantes

Os campos e valores apresentados na ferramenta são destinados à demonstração e organização do projeto.

Os valores reais utilizados em uma declaração devem ser conferidos diretamente nos documentos oficiais fornecidos pelas instituições e demais fontes responsáveis pelas informações.

A planilha não substitui o sistema oficial de declaração da Receita Federal nem orientação profissional. Sua finalidade é auxiliar na organização e conferência das informações.
